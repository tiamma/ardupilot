# VTOL偏航PID参数说明

## 📋 概述

VTOL垂起模式下的偏航控制使用**串级PID控制**，通过副翼输出来纠正偏航角度。所有PID参数都可以在地面站中实时调整。

---

## ⚙️ 参数列表

### **外环：角度控制**

| 参数名 | 默认值 | 范围 | 说明 |
|--------|--------|------|------|
| `VTOL_YAW_ANG_P` | 2.0 | 0.5 - 10.0 | 角度P增益（角度→角速度） |

**作用**：将角度误差转换为期望角速度
```
期望角速度 = 角度误差 × VTOL_YAW_ANG_P
```

---

### **内环：角速度控制**

| 参数名 | 默认值 | 范围 | 说明 |
|--------|--------|------|------|
| `VTOL_YAW_RT_P` | 0.5 | 0.1 - 2.0 | 角速度P增益 |
| `VTOL_YAW_RT_I` | 0.1 | 0.0 - 1.0 | 角速度I增益 |
| `VTOL_YAW_RT_D` | 0.02 | 0.0 - 0.2 | 角速度D增益 |
| `VTOL_YAW_RT_IMAX` | 10.0 | 0 - 50 | 积分限幅 |
| `VTOL_YAW_RT_MAX` | 90.0 | 10 - 180 | 最大角速度（deg/s） |

**作用**：将角速度误差转换为副翼输出
```
P输出 = 角速度误差 × VTOL_YAW_RT_P
I输出 = ∫(角速度误差 × dt) × VTOL_YAW_RT_I
D输出 = d(角速度误差)/dt × VTOL_YAW_RT_D
总输出 = P + I + D
```

---

## 🎯 控制流程

```
偏航角度误差
    ↓
[外环] VTOL_YAW_ANG_P
    ↓
期望角速度 (限制在 ±VTOL_YAW_RT_MAX)
    ↓
角速度误差 = 期望角速度 - 当前角速度
    ↓
[内环] PID控制
    ├─ P: VTOL_YAW_RT_P
    ├─ I: VTOL_YAW_RT_I (限幅: VTOL_YAW_RT_IMAX)
    └─ D: VTOL_YAW_RT_D
    ↓
副翼输出
```

## 🔧 参数调整指南

### **1. 响应太慢**

#### **症状**
- 偏航纠正速度慢
- 角度误差长时间存在
- 飞机转动缓慢

#### **解决方案**
```
增加外环增益：
VTOL_YAW_ANG_P = 3.0  (从2.0增加)

或增加内环P增益：
VTOL_YAW_RT_P = 0.7   (从0.5增加)

或增加最大角速度：
VTOL_YAW_RT_MAX = 120 (从90增加)
```

---

### **2. 抖动/振荡**

#### **症状**
- 偏航方向来回摆动
- 副翼输出频繁变化
- 飞机不稳定

#### **解决方案**
```
减小外环增益：
VTOL_YAW_ANG_P = 1.5  (从2.0减小)

或减小内环P增益：
VTOL_YAW_RT_P = 0.3   (从0.5减小)

或增加D增益抑制振荡：
VTOL_YAW_RT_D = 0.05  (从0.02增加)
```

---

### **3. 稳态误差**

#### **症状**
- 偏航角度始终有小误差
- 无法完全对准目标角度
- 误差在1-5度范围

#### **解决方案**
```
增加I增益：
VTOL_YAW_RT_I = 0.15  (从0.1增加)

或增加积分限幅：
VTOL_YAW_RT_IMAX = 15 (从10增加)
```

---

### **4. 积分饱和**

#### **症状**
- 长时间偏航后响应变慢
- 控制输出达到最大值
- 纠正过度

#### **解决方案**
```
减小积分限幅：
VTOL_YAW_RT_IMAX = 5  (从10减小)

或减小I增益：
VTOL_YAW_RT_I = 0.05  (从0.1减小)
```

---

## 📊 调参步骤

### **步骤1：基础测试**

1. **使用默认参数**
   ```
   VTOL_YAW_ANG_P = 2.0
   VTOL_YAW_RT_P = 0.5
   VTOL_YAW_RT_I = 0.1
   VTOL_YAW_RT_D = 0.02
   VTOL_YAW_RT_IMAX = 10.0
   VTOL_YAW_RT_MAX = 90.0
   ```

2. **悬停测试**
   - 进入QHOVER模式
   - 手动偏航30度
   - 观察自动纠正效果

3. **记录现象**
   - 响应速度
   - 是否抖动
   - 稳态误差

---

### **步骤2：调整外环**

1. **如果响应太慢**
   ```
   VTOL_YAW_ANG_P += 0.5
   ```
   重复测试，直到响应满意

2. **如果抖动**
   ```
   VTOL_YAW_ANG_P -= 0.5
   ```
   减小直到稳定

3. **最佳范围**
   ```
   保守：1.5 - 2.0
   标准：2.0 - 3.0
   激进：3.0 - 4.0
   ```

---

### **步骤3：调整内环P**

1. **增加P增益**
   ```
   VTOL_YAW_RT_P = 0.5 → 0.6 → 0.7
   ```
   每次增加0.1，测试响应

2. **找到临界点**
   - 开始抖动的P值
   - 记录为 P_critical

3. **设置最终值**
   ```
   VTOL_YAW_RT_P = P_critical × 0.7
   ```
   留有安全裕度

---

### **步骤4：调整内环I**

1. **测试稳态误差**
   - 偏航30度
   - 等待10秒
   - 记录剩余误差

2. **如果误差 > 2度**
   ```
   VTOL_YAW_RT_I += 0.05
   ```
   逐步增加

3. **注意积分饱和**
   - 如果纠正过度
   - 减小 VTOL_YAW_RT_IMAX

---

### **步骤5：调整内环D**

1. **如果有高频抖动**
   ```
   VTOL_YAW_RT_D = 0.02 → 0.05 → 0.08
   ```
   增加D增益抑制

2. **注意噪声**
   - D增益过大会放大传感器噪声
   - 建议不超过 0.1

---


## 📈 日志分析

### **关键变量**

在地面站查看实时数据：
```
angle_error      - 角度误差
current_yaw_rate - 当前角速度
desired_yaw_rate - 期望角速度
p_output         - P项输出
i_output         - I项输出
d_output         - D项输出
pid_output       - 总输出
```

### **分析方法**

1. **响应速度**
   ```
   观察 angle_error 从30度降到0的时间
   理想：2-5秒
   ```

2. **超调量**
   ```
   angle_error 是否越过0并反向
   理想：< 5度
   ```

3. **稳态误差**
   ```
   最终 angle_error 的值
   理想：< 2度
   ```

4. **振荡频率**
   ```
   angle_error 来回摆动的频率
   理想：无振荡
   ```

## ⚠️ 注意事项

### **1. 参数范围**
- 不要超出建议范围
- 极端值可能导致失控

### **2. 逐步调整**
- 每次只改一个参数
- 每次改动不超过20%
- 充分测试后再继续

### **3. 安全测试**
- 先地面测试
- 再低空悬停测试
- 最后正常飞行

### **4. 备份参数**
- 调参前保存当前参数
- 记录每次修改
- 便于回退

## 🎓 理论基础

### **串级PID控制**

```
外环（慢）：角度 → 角速度
内环（快）：角速度 → 输出
```

**优势**：
- 响应快速
- 稳定性好
- 抗干扰能力强

### **PID各项作用**

| 项 | 作用 | 副作用 |
|----|------|--------|
| **P** | 快速响应 | 可能超调 |
| **I** | 消除稳态误差 | 可能积分饱和 |
| **D** | 抑制振荡 | 放大噪声 |
