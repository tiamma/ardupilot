# Q_TILT_ANG_SCALE 参数说明

## 📋 新增参数

### **Q_TILT_ANG_SCALE**

**参数信息**：
```
参数名：Q_TILT_ANG_SCALE
索引：52
默认值：5.0 度
范围：0 - 90 度
单位：deg（度）
增量：0.5
用户级别：Standard
```

**说明**：
通道16控制倾转角度的缩放系数。通道16的归一化输入（-1到1）乘以此参数得到目标倾转角度。

---

## 🎯 功能说明

### **计算公式**
```cpp
manual_target_tilt_angle = ch16_input × TILT_ANG_SCALE

其中：
- ch16_input: 通道16归一化输入 [-1.0, 1.0]
- TILT_ANG_SCALE: 缩放系数（本参数）
- manual_target_tilt_angle: 目标倾转角度（度）
```

## 📈 使用建议

### **初始设置**
```
1. 从默认值开始：Q_TILT_ANG_SCALE = 5.0
2. 地面测试通道16控制
3. 观察倾转角度响应
4. 根据需求调整
```

---

### **调整原则**

#### **增加参数值（扩大范围）**
```
现象：满杆时角度不够大
操作：增加 Q_TILT_ANG_SCALE

例如：
5.0 → 7.5 → 10.0

注意：
⚠️ 角度过大可能影响稳定性
⚠️ 建议每次增加2.5°
```

---

#### **减小参数值（精细控制）**
```
现象：控制不够精细，角度变化太快
操作：减小 Q_TILT_ANG_SCALE

例如：
5.0 → 3.0 → 2.5

注意：
⚠️ 角度过小可能不够用
⚠️ 建议每次减小1.0°
```

## ⚠️ 注意事项

### **1. 角度限制**
```
代码中已限制：-90° 到 +90°

即使设置 Q_TILT_ANG_SCALE = 100
满杆角度也不会超过 ±90°

constrain_float(manual_target_tilt_angle, -90.0f, 90.0f);
```

---

### **2. 参数范围**
```
配置范围：0 - 90 度

推荐范围：2.5 - 15 度

极限范围：
- 最小：0.5 度（超精细）
```

### **3. 飞行安全**

## 🔧 故障排除

### **问题1：角度不变**
```
现象：调整通道16无反应
原因：
- 通道16未配置
- 参数未生效
- 代码未使用参数

解决：
1. 检查通道16信号
2. 重启飞控
3. 查看GCS参数列表
```

---

### **问题2：角度范围不对**
```
现象：满杆角度不是预期值
原因：
- Q_TILT_ANG_SCALE 设置错误
- 通道16校准问题

解决：
1. 检查参数值
2. 校准通道16行程
3. 验证 ch16_input 范围
```

---

### **问题3：角度跳变**
```
现象：角度突然变化
原因：
- 通道16信号干扰
- 参数修改未保存

解决：
1. 检查遥控器信号质量
2. 确认参数已写入
3. 重启飞控
```
