# 双旋翼轨迹规划集成说明

## 概述

已将最速曲线（S曲线）轨迹规划算法集成到双旋翼控制系统中，用于生成最优的角度变化轨迹。

## 功能特性

### 1. S曲线轨迹规划
- **加速阶段**: 平滑加速到最大角速度
- **匀速阶段**: 保持最大角速度（如果需要）
- **减速阶段**: 平滑减速到目标角度
- **自动优化**: 根据角度变化自动选择梯形或三角形速度曲线

### 2. 参数配置

| 参数 | 名称 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `Q_TILT_TRAJ_EN` | 启用轨迹规划 | 0 | 0-1 | 0=禁用, 1=启用 |
| `Q_TILT_TRAJ_RATE` | 最大角速度 | 90 | 30-180 | 度/秒 |
| `Q_TILT_TRAJ_ACCEL` | 最大角加速度 | 180 | 60-360 | 度/秒² |

### 3. 工作原理

```
原始目标角度 → [轨迹规划] → 平滑目标角度 → [PID控制] → 电机输出
                    ↓
              S曲线轨迹生成
              (加速-匀速-减速)
```

## 使用方法

### 启用轨迹规划


## 参数调整指南

### 1. 最大角速度 (TRAJ_RATE)

**保守设置** (稳定优先):
```
Q_TILT_TRAJ_RATE = 60    # 慢速平滑
```

**标准设置** (平衡):
```
Q_TILT_TRAJ_RATE = 90    # 默认值
```

**激进设置** (速度优先):
```
Q_TILT_TRAJ_RATE = 120   # 快速响应
```

### 2. 最大角加速度 (TRAJ_ACCEL)

**保守设置**:
```
Q_TILT_TRAJ_ACCEL = 120  # 柔和加速
```

**标准设置**:
```
Q_TILT_TRAJ_ACCEL = 180  # 默认值
```

**激进设置**:
```
Q_TILT_TRAJ_ACCEL = 240  # 快速加速
```

### 3. 调整原则

**关系公式**:
```
最小角度变化 = 2 × (max_rate² / max_accel)

例如: max_rate=90, max_accel=180
最小角度 = 2 × (90² / 180) = 90度
```

**建议比例**:
```
max_accel = 2 × max_rate

例如:
- max_rate = 60  → max_accel = 120
- max_rate = 90  → max_accel = 180
- max_rate = 120 → max_accel = 240
```

## 代码实现细节

### 1. 轨迹初始化

```cpp
void trajectory_init(float start_angle, float end_angle)
{
    // 计算角度变化
    float angle_delta = fabsf(end_angle - start_angle);
    
    // 计算加速时间
    float t_accel = max_rate / max_accel;
    
    // 判断轨迹类型
    if (2 * angle_accel < angle_delta) {
        // 梯形曲线
        traj_has_constant_phase = true;
    } else {
        // 三角形曲线
        traj_has_constant_phase = false;
    }
}
```

### 2. 角度计算

```cpp
float trajectory_get_angle(float t)
{
    if (t < t_accel) {
        // 加速阶段: angle = 0.5 * a * t²
        angle = start + sign * 0.5 * accel * t * t;
    } else if (has_constant && t < t_accel + t_const) {
        // 匀速阶段: angle = angle_accel + v * t
        angle = start + angle_accel + sign * max_rate * t_const;
    } else {
        // 减速阶段: angle = end - 0.5 * a * t_remaining²
        angle = end - sign * 0.5 * accel * t_remaining * t_remaining;
    }
}
```

### 3. 目标检测

```cpp
// 检测目标变化
static float last_target = 0;
if (fabsf(target_new - last_target) > 0.5f) {
    // 目标改变超过0.5度，重新规划轨迹
    trajectory_init(current_angle, target_new);
    last_target = target_new;
}
```

## 故障排查

### 问题1: 响应变慢

**症状**: 启用轨迹规划后响应更慢

**原因**: 参数设置过于保守

**解决**:
```
增大 Q_TILT_TRAJ_RATE
增大 Q_TILT_TRAJ_ACCEL
```

### 问题2: 仍有超调

**症状**: 启用轨迹规划后仍有超调

**原因**: PID参数不匹配

**解决**:
```
减小 Q_TILT_P_ANG_P
减小 Q_TILT_P_RAT_P
增加 Q_TILT_P_ANG_D
```

### 问题3: 轨迹不平滑

**症状**: 角度变化不平滑

**原因**: 目标检测阈值过小

**解决**:
修改代码中的阈值:
```cpp
if (fabsf(target_new - last_target) > 0.5f) {
    // 改为更大的值，如 1.0f 或 2.0f
}
```

## 技术细节

### 数学公式

**加速阶段**:
```
θ(t) = θ₀ + ½at²
ω(t) = at
α(t) = a
```

**匀速阶段**:
```
θ(t) = θ₁ + ω_max × (t - t₁)
ω(t) = ω_max
α(t) = 0
```

**减速阶段**:
```
θ(t) = θ_end - ½a(T - t)²
ω(t) = a(T - t)
α(t) = -a
```
