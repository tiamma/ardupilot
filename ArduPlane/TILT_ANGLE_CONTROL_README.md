# 倾转角度手动控制说明

## 📋 功能概述

通过通道12切换目标角度控制模式：
- **通道12低位**：使用通道9六段开关（固定角度）
- **通道12高位**：使用通道2动态调整角度（连续可调）

---

## 🎮 控制方式

### **模式1：六段开关（CH12低位）**

使用通道9六段开关选择固定角度：

| 通道9位置 | PWM范围 | 目标角度 | 说明 |
|----------|---------|---------|------|
| 位置1 | 1000-1166 | 0° | 垂直 |
| 位置2 | 1167-1333 | 18° | - |
| 位置3 | 1334-1500 | 36° | - |
| 位置4 | 1501-1667 | 54° | - |
| 位置5 | 1668-1834 | 72° | - |
| 位置6 | 1835-2000 | 90° | 水平 |

**特点**：
- 快速切换到预设角度
- 适合标准飞行模式切换

---

### **模式2：动态调整（CH12高位）⭐**

使用通道2（俯仰摇杆）连续调整目标角度：

| 操作 | 效果 | 变化率 |
|------|------|--------|
| **前推摇杆** | 增加角度（向水平） | 正比于摇杆偏移量 |
| **后拉摇杆** | 减少角度（向垂直） | 正比于摇杆偏移量 |
| **摇杆中位** | 保持当前角度 | 0 |

**控制逻辑**：
```
角度变化率 = 摇杆输入 × 最大变化率
新角度 = 当前角度 + 角度变化率 × 时间间隔
限制范围：0° - 90°
```

**特点**：
- 精细调整角度
- 平滑过渡
- 实时响应

---

## ⚙️ 参数配置

### **Q_TILT_TILT_RT**（最大变化率）

| 参数 | 默认值 | 单位 | 范围 | 说明 |
|------|--------|------|------|------|
| `Q_TILT_TILT_RT` | 10.0 | 度/秒 | 0.1 - 90 | 摇杆满偏时的最大角度变化率 |

**调整建议**：
- **保守设置**：5-10 度/秒（平滑过渡）
- **标准设置**：10-20 度/秒（平衡）
- **激进设置**：20-45 度/秒（快速响应）
- **最小限制**：0.1 度/秒（防止参数错误）

## 🔧 实现细节

### **1. 时间间隔计算**
```cpp
float dt_s = 0.02f;  // 默认50Hz
if (last_tilt_angle_update_ms != 0) {
    dt_s = (now_ms - last_tilt_angle_update_ms) * 0.001f;
    // 异常保护
    if (dt_s > 1.0f || dt_s <= 0.0f) {
        dt_s = 0.02f;
    }
}
```

### **2. 摇杆输入处理**
```cpp
ch2_input = plane.channel_pitch->norm_input();  // [-1, 1]

// 死区处理（±5%）
if (fabsf(ch2_input) < 0.05f) {
    ch2_input = 0.0f;
}
```

### **3. 角度更新**
```cpp
// 计算变化率
float max_rate = MAX(tilt_angle_rate_max, 0.1f);
float angle_rate = ch2_input * max_rate;

// 积分更新
manual_target_tilt_angle += angle_rate * dt_s;

// 限幅
manual_target_tilt_angle = constrain_float(manual_target_tilt_angle, 0.0f, 90.0f);
```

### **4. 模式切换同步**
```cpp
// 从CH12高位切换到低位时
// 自动同步手动角度到六段开关位置
if (!ch12_high) {
    manual_target_tilt_angle = target_tilt_angle;  // 同步
}
```

## 📊 使用示例

### **场景1：起飞到巡航**

1. **起飞**（CH12低位）
   - CH9位置1 → 0°（垂直）
   - 起飞悬停

2. **切换到动态模式**（CH12高位）
   - 当前角度保持0°
   - 准备加速

3. **加速前飞**
   - 缓慢前推CH2
   - 角度从0°平滑增加到90°
   - 过渡到水平飞行

### **场景2：精细调整**

1. **快速定位**（CH12低位）
   - CH9位置4 → 54°
   - 快速到达大致角度

2. **精细调整**（CH12高位）
   - 前推CH2：54° → 60°
   - 后拉CH2：60° → 57°
   - 找到最佳角度

### **场景3：降落**

1. **减速**（CH12高位）
   - 后拉CH2
   - 角度从90°平滑减少

2. **悬停准备**
   - 继续后拉至0°
   - 切换到垂直模式

3. **降落**（CH12低位）
   - CH9位置1 → 0°
   - 锁定垂直姿态

| **精度** | ±0° | ±0.1° |
| **操作复杂度** | 简单 | 中等 |
| **适用场景** | 标准模式切换 | 精细控制 |

### **核心优势**

1. **平滑过渡**：避免角度突变引起的姿态扰动
2. **精细控制**：可以找到最优角度
3. **实时调整**：根据飞行状态动态优化
4. **兼容性好**：保留六段开关作为备用

## ⚠️ 注意事项

### **1. 摇杆冲突**
- CH12高位时，CH2控制角度，**不控制速度**
- 速度控制功能暂时失效
- 建议：巡航时使用角度控制，悬停时使用速度控制

### **2. 角度限制**
- 最小：0°（垂直）
- 最大：90°（水平）
- 超出范围自动限幅

### **3. 变化率限制**
- 最小：0.1°/秒
- 最大：由参数 `Q_TILT_TILT_RT` 决定
- 摇杆满偏时达到最大变化率

### **4. 模式切换**
- CH12切换时，角度会自动同步
- 避免切换时角度跳变
- 建议：在稳定飞行时切换模式

## 🔍 故障排查

### **问题1：摇杆无响应**
- 检查CH12是否在高位
- 检查CH2是否有效输入
- 检查参数 `Q_TILT_TILT_RT` 是否 > 0.1

### **问题2：角度变化太快**
- 减小 `Q_TILT_TILT_RT`
- 检查摇杆死区是否正常

### **问题3：角度变化太慢**
- 增加 `Q_TILT_TILT_RT`
- 检查摇杆是否满偏

### **问题4：模式切换异常**
- 检查CH12信号是否稳定
- 观察角度同步是否正常
