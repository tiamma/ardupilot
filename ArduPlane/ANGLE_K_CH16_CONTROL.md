# 通道16控制 angle_k 参数说明

## 📋 概述

通过遥控器16通道实时调整 `angle_k` 参数，控制角度环和角速度环的混合比例。

---

## 🎯 功能说明

### **angle_k 的作用**
```cpp
pitch_differential = pitch_angle_diff × angle_k + 
                     pitch_rate_pid × (1 - angle_k)
```

**混合控制**：
- `angle_k = 0.0`：100% 角速度PID控制
- `angle_k = 0.5`：50% 角度 + 50% 角速度
- `angle_k = 1.0`：100% 角度控制

---

## 🔧 实现方式

### **代码实现**
```cpp
// 从16通道读取angle_k值（通道16，索引15）
float angle_k = 0.1f;  // 默认值
RC_Channel *ch16 = RC_Channels::rc_channel(15);  // 通道16（索引从0开始）
if (ch16 != nullptr) {
    // 获取归一化输入 [-1, 1]
    float ch16_input = ch16->norm_input();
    // 映射到 [0, 1] 范围
    angle_k = (ch16_input + 1.0f) * 0.5f;
    // 限制范围
    angle_k = constrain_float(angle_k, 0.0f, 1.0f);
}
```

---

## 📊 输入映射

### **通道16输入 → angle_k 映射**

| 通道16位置 | PWM值 | norm_input | angle_k | 控制模式 |
|-----------|-------|------------|---------|---------|
| 最低位 | 1000 | -1.0 | 0.0 | 纯角速度PID |
| 1/4位 | 1250 | -0.5 | 0.25 | 25%角度+75%角速度 |
| 中位 | 1500 | 0.0 | 0.5 | 50%角度+50%角速度 |
| 3/4位 | 1750 | +0.5 | 0.75 | 75%角度+25%角速度 |
| 最高位 | 2000 | +1.0 | 1.0 | 纯角度控制 |

---

### **映射公式**
```
angle_k = (ch16_input + 1.0) × 0.5

示例：
ch16_input = -1.0 → angle_k = (-1.0 + 1.0) × 0.5 = 0.0
ch16_input = -0.5 → angle_k = (-0.5 + 1.0) × 0.5 = 0.25
ch16_input =  0.0 → angle_k = ( 0.0 + 1.0) × 0.5 = 0.5
ch16_input = +0.5 → angle_k = (+0.5 + 1.0) × 0.5 = 0.75
ch16_input = +1.0 → angle_k = (+1.0 + 1.0) × 0.5 = 1.0
```

---

## 🎮 控制效果

### **angle_k = 0.0（纯角速度PID）**
```
pitch_differential = 0 × pitch_angle_diff + 1.0 × pitch_rate_pid
                   = pitch_rate_pid

特点：
✅ 响应快速
✅ 适合特技飞行
❌ 不保持角度
❌ 需要持续操作
```

---

### **angle_k = 0.1（默认值）**
```
pitch_differential = 0.1 × pitch_angle_diff + 0.9 × pitch_rate_pid

特点：
✅ 主要靠角速度控制
✅ 少量角度修正
✅ 平衡响应和稳定
```

---

### **angle_k = 0.5（平衡模式）**
```
pitch_differential = 0.5 × pitch_angle_diff + 0.5 × pitch_rate_pid

特点：
✅ 角度和角速度各占50%
✅ 响应和稳定平衡
✅ 适合一般飞行
```

---

### **angle_k = 1.0（纯角度控制）**
```
pitch_differential = 1.0 × pitch_angle_diff + 0 × pitch_rate_pid
                   = pitch_angle_diff

特点：
✅ 强力保持角度
✅ 自动回中
❌ 响应较慢
❌ 可能振荡
```

## 🛠️ 遥控器设置

### **通道16配置**

#### **1. 分配通道**
```
遥控器设置：
- 通道16 → 旋钮/开关/滑块
- 推荐：使用旋钮（可连续调节）
```

#### **2. 行程设置**
```
PWM范围：1000 - 2000 μs
中位：1500 μs
死区：可选（建议±10 μs）
```

#### **3. 反向设置**
```
正向：最低位 = 0.0，最高位 = 1.0
反向：最低位 = 1.0，最高位 = 0.0
推荐：正向
```

## ⚠️ 注意事项

### **1. 通道16必须配置**
```
问题：如果通道16未配置或信号丢失
结果：使用默认值 angle_k = 0.1

检查：
- 遥控器是否输出通道16
- 接收机是否支持16通道
- 飞控是否接收到信号
```

---

### **2. 避免极端值**
```
angle_k = 0.0：
⚠️ 完全无角度控制
⚠️ 可能难以控制
⚠️ 建议最小值 0.1

angle_k = 1.0：
⚠️ 完全无角速度阻尼
⚠️ 可能振荡
⚠️ 建议最大值 0.9
```

---

### **3. 飞行中调整**
```
✅ 可以飞行中实时调整
✅ 立即生效
⚠️ 大幅度调整可能导致姿态突变
⚠️ 建议小幅度渐进调整
```

## 🔧 故障排除

### **问题1：通道16无效**
```
现象：调整通道16无反应
原因：
- 通道未配置
- 接收机不支持
- 信号线未连接

解决：
1. 检查遥控器通道输出
2. 检查接收机通道数
3. 检查飞控接线
4. 查看GCS参数 RCx_OPTION
```

---

### **问题2：angle_k 始终为默认值**
```
现象：angle_k 始终为 0.1
原因：ch16 == nullptr

解决：
1. 确认通道16信号正常
2. 检查 RC_Channels::rc_channel(15) 返回值
3. 添加调试输出确认
```

---

### **问题3：控制不稳定**
```
现象：调整 angle_k 后振荡
原因：
- angle_k 过大（>0.9）
- PID参数不匹配

解决：
1. 减小 angle_k
2. 调整角度环P增益
3. 增加角速度环D增益
```

## 💡 高级应用

### **应用1：自动切换模式**
```cpp
// 根据飞行状态自动调整 angle_k
if (fabsf(rc_pitch_input) < 0.05f) {
    // 悬停时增加角度控制
    angle_k = MAX(angle_k, 0.5f);
} else {
    // 机动时减少角度控制
    angle_k = MIN(angle_k, 0.3f);
}
```

---

### **应用2：速度相关调整**
```cpp
// 根据速度调整 angle_k
float speed_factor = fabsf(current_velocity_mps) / 5.0f;  // 0-1
angle_k = angle_k * (1.0f - speed_factor * 0.5f);  // 高速时减小
```

---

### **应用3：三段开关控制**
```cpp
// 使用三段开关快速切换
if (ch16_input < -0.5f) {
    angle_k = 0.1f;  // 低位：快速模式
} else if (ch16_input > 0.5f) {
    angle_k = 0.8f;  // 高位：稳定模式
} else {
    angle_k = 0.5f;  // 中位：平衡模式
}
```
