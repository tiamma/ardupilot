# 速度控制灵敏度调整指南

## 📋 问题描述

速度控制前馈输出过于灵敏，导致：
- 响应过快，姿态抖动
- 操作不平滑
- 难以精细控制

---

## ✅ 解决方案：低通滤波器

### **实现原理**

使用**一阶低通滤波器**平滑前馈输出：

```cpp
filtered_output = filtered_output × (1 - α) + new_output × α
```

**参数说明**：
- `α` (alpha)：滤波系数，范围 0-1
- `α` 越小 → 响应越慢，越平滑
- `α` 越大 → 响应越快，越接近原始值

---

## 🔧 代码实现

### **1. 头文件添加状态变量（tiltrotor.h:229）**

```cpp
// 速度控制状态变量
float bicopter_vel_integral;          // 速度环积分项
float bicopter_last_vel_error;        // 上次速度误差（用于微分）
float bicopter_vel_feedforward_filtered; // 速度前馈滤波后的值 ⭐
```

### **2. 构造函数初始化（tiltrotor.cpp:400）**

```cpp
// 初始化速度控制状态变量
bicopter_vel_integral = 0.0f;
bicopter_last_vel_error = 0.0f;
bicopter_vel_feedforward_filtered = 0.0f;  // ⭐ 初始化为0
```

### **3. 滤波器应用（tiltrotor.cpp:1358-1363）**

```cpp
// 7. 低通滤波平滑前馈输出，降低灵敏度
// 滤波系数：0.1 = 较慢响应，0.5 = 中等响应，0.9 = 快速响应
const float filter_alpha = 0.3f;  // 可调整：0.1-0.5之间
bicopter_vel_feedforward_filtered = bicopter_vel_feedforward_filtered * (1.0f - filter_alpha) + 
                                    velocity_feedforward * filter_alpha;
velocity_feedforward = bicopter_vel_feedforward_filtered;
```

## ⚙️ 参数调整

### **滤波系数 `filter_alpha`**

| 系数值 | 响应速度 | 平滑度 | 适用场景 |
|--------|---------|--------|---------|
| **0.1** | 很慢 | 非常平滑 | 新手、大风、载重 |
| **0.2** | 慢 | 平滑 | 保守飞行 |
| **0.3** | 中等 ⭐ | 平衡 | **推荐默认值** |
| **0.4** | 较快 | 较灵敏 | 熟练操作 |
| **0.5** | 快 | 灵敏 | 竞速、特技 |
| **0.7-0.9** | 很快 | 接近原始 | 调试、测试 |

## 📊 效果对比

### **修改前（无滤波）**

```
摇杆输入 → 速度误差 → PID计算 → 前馈输出 → 电机
                                    ↑
                                 直接输出
                                 响应快但抖动
```

**问题**：
- 输出跟随输入瞬间变化
- 姿态抖动
- 操作不平滑

---

### **修改后（低通滤波）**

```
摇杆输入 → 速度误差 → PID计算 → 前馈输出 → 滤波器 → 电机
                                              ↑
                                          平滑输出
                                          响应稳定
```

**优势**：
- 输出平滑过渡
- 姿态稳定
- 操作舒适

## 📈 滤波器特性

### **时间常数计算**

假设控制频率 = 50Hz（dt = 0.02s）

| α | 时间常数 τ | 达到63%需要 | 达到95%需要 |
|---|-----------|------------|------------|
| 0.1 | 0.18s | 0.18s | 0.54s |
| 0.2 | 0.08s | 0.08s | 0.24s |
| 0.3 | 0.047s | 0.047s | 0.14s |
| 0.4 | 0.03s | 0.03s | 0.09s |
| 0.5 | 0.02s | 0.02s | 0.06s |

**时间常数公式**：`τ = dt / α`

const float filter_alpha = 0.2f;  // 保守设置

```cpp

```

### **步骤3：找到最佳值**

**目标**：
- ✅ 响应足够快
- ✅ 姿态足够稳
- ✅ 操作足够平滑

**记录**：
```
α = 0.2: 太慢，响应迟钝
α = 0.3: 刚好，平衡最佳 ⭐
α = 0.4: 稍快，轻微抖动
```

## 🔍 其他降低灵敏度的方法

### **方案2：降低PID增益**

如果滤波器还不够，可以降低速度控制PID增益：

```cpp
// 参数调整
Q_TILT_V_P = 0.3  // 从0.5降低到0.3
Q_TILT_V_I = 0.05 // 从0.1降低到0.05
Q_TILT_V_D = 0.01 // 从0.02降低到0.01
```

**效果**：
- P增益降低 → 响应变慢
- I增益降低 → 稳态误差增大
- D增益降低 → 阻尼减小

---

### **方案3：限制最大俯仰角**

降低速度控制的最大俯仰角输出：

```cpp
// 参数调整
Q_TILT_V_P_MX = 10  // 从15度降低到10度
```

**效果**：
- 最大输出受限
- 响应幅度减小
- 更加温和

---

### **方案4：增加死区**

增加速度误差死区，减少小幅度抖动：

```cpp
// 在速度误差计算后添加死区
if (fabsf(velocity_error) < 0.2f) {  // 0.2 m/s 死区
    velocity_error = 0.0f;
}
```

**效果**：
- 小误差不响应
- 减少抖动
- 可能增加稳态误差

## ⚠️ 注意事项

### **1. 滤波延迟**

- 滤波会引入延迟
- α 越小，延迟越大
- 需要在平滑度和响应速度之间平衡

### **2. 初始化**

- 滤波器初始值为0
- 首次使用会有短暂过渡
- 正常现象，无需担心

### **3. 参数持久化**

- `filter_alpha` 是常量，不是参数
- 修改需要重新编译
- 如需动态调整，可改为AP_Float参数

### **4. 组合使用**

可以同时使用多种方法：
```
低通滤波 + 降低P增益 + 限制最大角度
```

但要避免过度调整导致响应太慢。

## 💡 高级技巧

### **自适应滤波系数**

根据速度误差大小动态调整滤波系数：

```cpp
// 误差大时快速响应，误差小时平滑输出
float adaptive_alpha;
if (fabsf(velocity_error) > 1.0f) {
    adaptive_alpha = 0.5f;  // 大误差：快速响应
} else {
    adaptive_alpha = 0.2f;  // 小误差：平滑输出
}
```

### **双级滤波**

先快速滤波，再慢速滤波：

```cpp
// 第一级：快速滤波（α=0.5）
float stage1 = stage1 * 0.5f + velocity_feedforward * 0.5f;

// 第二级：慢速滤波（α=0.3）
float stage2 = stage2 * 0.7f + stage1 * 0.3f;
```
