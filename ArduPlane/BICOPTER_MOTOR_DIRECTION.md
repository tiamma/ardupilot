# 双旋翼电机方向配置参数

## 概述

双旋翼控制系统提供了四个方向控制参数，用于灵活配置左右电机对俯仰和偏航控制的响应方向。这些参数允许适应不同的机械安装方式和控制需求。

## 参数列表

| 参数 | 全称 | 默认值 | 可选值 | 说明 |
|------|------|--------|--------|------|
| `Q_TILT_L_P_SIGN` | Left Pitch Sign | 1 | -1, 0, 1 | 左电机俯仰方向 |
| `Q_TILT_R_P_SIGN` | Right Pitch Sign | -1 | -1, 0, 1 | 右电机俯仰方向 |
| `Q_TILT_L_Y_SIGN` | Left Yaw Sign | -1 | -1, 0, 1 | 左电机偏航方向 |
| `Q_TILT_R_Y_SIGN` | Right Yaw Sign | 1 | -1, 0, 1 | 右电机偏航方向 |

## 参数值说明

- **1**: 正向（Normal）- 正常方向控制
- **0**: 禁用（Disabled）- 该电机不参与此轴控制
- **-1**: 反向（Reversed）- 反向控制

## 控制公式

```cpp
left_motor  = base_output + left_pitch_sign  * pitch_diff - left_yaw_sign  * yaw_diff
right_motor = base_output + right_pitch_sign * pitch_diff + right_yaw_sign * yaw_diff
```

其中：
- `base_output`: 基础位置（通常为0.5，对应舵机中位500）
- `pitch_diff`: 俯仰差分输出（-1.0到1.0）
- `yaw_diff`: 偏航差分输出（-1.0到1.0）

## 默认配置（标准双旋翼）

```
Q_TILT_L_P_SIGN = 1   # 左电机俯仰正向
Q_TILT_R_P_SIGN = -1  # 右电机俯仰反向
Q_TILT_L_Y_SIGN = -1  # 左电机偏航反向
Q_TILT_R_Y_SIGN = 1   # 右电机偏航正向
```

### 默认配置的控制效果

#### 俯仰控制
```
抬头（pitch_diff > 0）：
  左电机 = base + (+1) * pitch_diff  → 增加
  右电机 = base + (-1) * pitch_diff  → 减少
  效果：左增右减，机头抬起

低头（pitch_diff < 0）：
  左电机 = base + (+1) * pitch_diff  → 减少
  右电机 = base + (-1) * pitch_diff  → 增加
  效果：左减右增，机头下降
```

#### 偏航控制
```
左转（yaw_diff > 0）：
  左电机 = base - (-1) * yaw_diff  → 增加
  右电机 = base + (+1) * yaw_diff  → 增加
  效果：两侧都增加倾转角，产生左转力矩

右转（yaw_diff < 0）：
  左电机 = base - (-1) * yaw_diff  → 减少
  右电机 = base + (+1) * yaw_diff  → 减少
  效果：两侧都减少倾转角，产生右转力矩
```

## 配置场景

### 场景1: 标准配置（默认）
**适用**：标准双旋翼布局，左右电机对称安装

```
Q_TILT_L_P_SIGN = 1
Q_TILT_R_P_SIGN = -1
Q_TILT_L_Y_SIGN = -1
Q_TILT_R_Y_SIGN = 1
```

### 场景2: 反向俯仰
**适用**：电机安装方向相反

```
Q_TILT_L_P_SIGN = -1
Q_TILT_R_P_SIGN = 1
Q_TILT_L_Y_SIGN = -1
Q_TILT_R_Y_SIGN = 1
```

### 场景3: 仅俯仰控制（禁用偏航）
**适用**：只需要俯仰控制，偏航由其他机构控制

```
Q_TILT_L_P_SIGN = 1
Q_TILT_R_P_SIGN = -1
Q_TILT_L_Y_SIGN = 0
Q_TILT_R_Y_SIGN = 0
```

### 场景4: 仅偏航控制（禁用俯仰）
**适用**：只需要偏航控制，俯仰由其他机构控制

```
Q_TILT_L_P_SIGN = 0
Q_TILT_R_P_SIGN = 0
Q_TILT_L_Y_SIGN = -1
Q_TILT_R_Y_SIGN = 1
```

### 场景5: 单电机控制
**适用**：只使用一个电机进行控制

```
# 只用左电机
Q_TILT_L_P_SIGN = 1
Q_TILT_R_P_SIGN = 0
Q_TILT_L_Y_SIGN = -1
Q_TILT_R_Y_SIGN = 0

# 或只用右电机
Q_TILT_L_P_SIGN = 0
Q_TILT_R_P_SIGN = -1
Q_TILT_L_Y_SIGN = 0
Q_TILT_R_Y_SIGN = 1
```

## 调试方法

### 1. 地面测试

**步骤**：
1. 设置所有符号参数为默认值
2. 解锁飞行器（在安全环境中）
3. 给俯仰指令，观察电机响应
4. 给偏航指令，观察电机响应

**预期结果**：
```
俯仰指令：抬头
  左电机应该增加倾转角
  右电机应该减少倾转角

偏航指令：左转
  左右电机都应该增加倾转角
```

### 2. 使用QGC监控

观察QGC消息输出：
```
Bi b:0.50 zt=0.50,ta=90.00 PE:2.3 PD:0.25 L:625 R:375
```

**分析**：
- **PE > 0**（需要抬头）时：
  - L应该 > 500（左电机增加）
  - R应该 < 500（右电机减少）
  
- 如果方向相反，调整符号参数

### 3. 日志分析

查看TILT日志：
```
PErr > 0 时：
  LOut 应该增加
  ROut 应该减少
```

如果不符合预期，调整相应的符号参数。

## 故障排查

### 问题1: 俯仰控制方向相反

**症状**：
- 给抬头指令，飞行器低头
- 给低头指令，飞行器抬头

**解决**：
```
# 同时反转两个俯仰符号
Q_TILT_L_P_SIGN = -1  # 原来是 1
Q_TILT_R_P_SIGN = 1   # 原来是 -1
```

### 问题2: 偏航控制方向相反

**症状**：
- 给左转指令，飞行器右转
- 给右转指令，飞行器左转

**解决**：
```
# 同时反转两个偏航符号
Q_TILT_L_Y_SIGN = 1   # 原来是 -1
Q_TILT_R_Y_SIGN = -1  # 原来是 1
```

### 问题3: 左右电机响应不对称

**症状**：
- 左电机响应正常，右电机不响应
- 或者相反

**检查**：
1. 确认电机物理连接正常
2. 检查对应的符号参数是否为0（禁用）
3. 检查舵机通道配置

**解决**：
```
# 确保符号不为0
Q_TILT_L_P_SIGN ≠ 0
Q_TILT_R_P_SIGN ≠ 0
```

### 问题4: 控制幅度不足

**症状**：
- 电机响应方向正确，但幅度太小

**原因**：
- 符号参数正确，但PID增益不足

**解决**：
- 不要修改符号参数
- 调整PID增益参数

## 高级应用

### 1. 非对称布局

如果左右电机安装位置或角度不对称：

```
# 根据实际机械结构调整
Q_TILT_L_P_SIGN = 1
Q_TILT_R_P_SIGN = -1  # 或根据需要调整
Q_TILT_L_Y_SIGN = -1
Q_TILT_R_Y_SIGN = 1
```

### 2. 混合控制

结合其他控制面（如副翼、升降舵）：

```
# 倾转电机主要负责俯仰
Q_TILT_L_P_SIGN = 1
Q_TILT_R_P_SIGN = -1
Q_TILT_L_Y_SIGN = 0   # 禁用偏航
Q_TILT_R_Y_SIGN = 0   # 偏航由方向舵控制
```

### 3. 测试和校准

**步骤1**: 单轴测试
```
# 先测试俯仰
Q_TILT_L_Y_SIGN = 0
Q_TILT_R_Y_SIGN = 0
# 确认俯仰方向正确后，再启用偏航
```

**步骤2**: 逐步启用
```
# 俯仰正确后
Q_TILT_L_Y_SIGN = -1
Q_TILT_R_Y_SIGN = 1
# 测试偏航
```

## 参数组合矩阵

| 配置 | L_P | R_P | L_Y | R_Y | 俯仰效果 | 偏航效果 |
|------|-----|-----|-----|-----|----------|----------|
| 标准 | 1 | -1 | -1 | 1 | 正常 | 正常 |
| 俯仰反向 | -1 | 1 | -1 | 1 | 反向 | 正常 |
| 偏航反向 | 1 | -1 | 1 | -1 | 正常 | 反向 |
| 全反向 | -1 | 1 | 1 | -1 | 反向 | 反向 |
| 仅俯仰 | 1 | -1 | 0 | 0 | 正常 | 禁用 |
| 仅偏航 | 0 | 0 | -1 | 1 | 禁用 | 正常 |

## 最佳实践

1. **首次配置**：
   - 使用默认值开始
   - 在地面安全测试
   - 逐个轴测试

2. **调整流程**：
   - 一次只改一个参数
   - 记录每次改动的效果
   - 保存工作配置

3. **文档记录**：
   - 记录最终的符号配置
   - 说明机械布局
   - 保存参数文件

4. **安全测试**：
   - 先在地面测试
   - 确认方向正确
   - 再进行飞行测试

```ini
Q_TILT_R_Y_SIGN = 1

```
