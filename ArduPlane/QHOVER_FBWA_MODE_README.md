# QHOVER模式自动切换FBWA控制说明

## 📋 功能概述

在QHOVER模式下，根据倾转角度自动切换控制方式：
- **倾转角度 ≤ 30°**：VTOL悬停控制（原有逻辑）
- **倾转角度 > 30°**：FBWA固定翼控制（新增功能）

同时支持通道12控制俯仰锁定功能。

---

## 🎯 控制逻辑

### **判断条件**

```cpp
if (tilt_angle_deg > 30.0f) {
    // FBWA风格控制
} else {
    // VTOL悬停控制
}
```

### **控制模式对比**

| 倾转角度 | 控制模式 | 横滚 | 俯仰 | 偏航 | 油门 |
|---------|---------|------|------|------|------|
| **0-30°** | VTOL悬停 | 速度控制 | 速度控制 | 角度锁定 | 高度保持 |
| **>30°** | FBWA固定翼 | 角度控制 | 角度控制 | 自由 | 手动 |

### **3. QHOVER模式切换（mode_qhover.cpp）**

#### **A. 倾转角度 > 30°（FBWA模式）**

```cpp

plane.nav_roll_cd = plane.channel_roll->norm_input() * plane.roll_limit_cd;

    // CH12高位：锁定5度

    // CH12低位：摇杆控制

```

#### **B. 倾转角度 ≤ 30°（VTOL模式）**

```cpp
// 保持原有VTOL悬停逻辑

plane.stabilize_vtol_yaw(angle_error);
```

## 🎮 操作说明

### **场景1：垂直起飞到巡航**

1. **起飞悬停**（倾转角度 = 0°）
   ```
   模式：QHOVER
   控制：VTOL悬停
   摇杆：控制速度和高度
   ```

2. **增加倾转角度**（0° → 30°）
   ```
   CH12高位 + CH2前推
   仍然是VTOL控制
   ```

3. **切换到固定翼**（30° → 90°）
   ```
   角度超过30°
   自动切换到FBWA控制
   摇杆：控制姿态角度
   ```

4. **巡航飞行**（倾转角度 = 90°）
   ```
   模式：QHOVER（但使用FBWA控制）
   CH12高位：俯仰锁定5°
   CH12低位：摇杆控制俯仰
   ```

---

### **场景2：巡航到降落**

1. **巡航**（倾转角度 = 90°）
   ```
   FBWA控制
   CH12高位：俯仰5°
   ```

2. **减速**（90° → 30°）
   ```
   CH12高位 + CH2后拉
   仍然是FBWA控制
   ```

3. **切换到悬停**（30° → 0°）
   ```
   角度低于30°
   自动切换到VTOL控制
   开始悬停减速
   ```

4. **降落**（倾转角度 = 0°）
   ```
   VTOL悬停控制
   垂直降落
   ```

## ⚙️ 通道12功能（CH12高位时）

### **倾转角度 ≤ 30°（VTOL模式）**
- **功能**：通道2控制目标倾转角度
- **俯仰**：速度控制（不受影响）

### **倾转角度 > 30°（FBWA模式）**
- **功能**：锁定俯仰角度 = 5°
- **俯仰**：固定5°，不响应摇杆

## 📊 控制参数对比

### **VTOL模式（≤30°）**

| 通道 | 功能 | 输出 |
|------|------|------|
| CH1（横滚） | 前后速度 | 速度指令 |
| CH2（俯仰） | 左右速度 | 速度指令 |
| CH3（油门） | 垂直速度 | 高度保持 |
| CH4（偏航） | 偏航速率 | 角度锁定 |

### **FBWA模式（>30°）**

| 通道 | 功能 | 输出 |
|------|------|------|
| CH1（横滚） | 横滚角度 | ±roll_limit |
| CH2（俯仰） | 俯仰角度* | ±pitch_limit |
| CH3（油门） | 油门 | 直接输出 |
| CH4（偏航） | 偏航 | 自由 |

**\*注**：CH12高位时锁定5°

## ⚠️ 注意事项

### **1. 30度切换点**
- **切换阈值**：30°（可根据需要调整）
- **建议范围**：25-35°
- **修改位置**：`mode_qhover.cpp:39`

### **2. 俯仰锁定角度**
- **当前值**：5°
- **适用场景**：巡航爬升
- **修改位置**：`mode_qhover.cpp:49`
- **可调整范围**：0-15°

### **3. 控制切换平滑性**
- 在30°附近切换时可能有轻微抖动
- 建议快速通过30°切换点
- 或增加滞后（例如：上升32°切换，下降28°切回）

### **4. CH12功能冲突**
- **≤30°**：CH12控制倾转角度
- **>30°**：CH12锁定俯仰角度
- 两种功能互不干扰

## 🎯 优势

### **1. 平滑过渡**
- 自动根据倾转角度切换控制模式
- 无需手动切换飞行模式
- 始终保持在QHOVER模式

### **2. 操作简化**
- 一个模式完成起飞到巡航
- 减少模式切换次数
- 降低操作复杂度

### **3. 安全性提升**
- 低角度自动使用VTOL控制（更稳定）
- 高角度自动使用固定翼控制（更高效）
- 避免错误的控制方式

### **4. 巡航优化**
- CH12高位锁定俯仰5°
- 适合长距离巡航
- 减少摇杆操作
