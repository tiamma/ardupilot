# 通道12强制完成转换功能说明

## 📋 功能概述

通过遥控器12通道强制完成VTOL转换过程，无需等待自动转换条件满足。

---

## 🎯 功能说明

### **代码实现**
```cpp
// 检查遥控器12通道，如果在高位则强制完成转换
int ch12_pwm = RC_Channels::get_radio_in(11);  // 通道12（索引11）
if (ch12_pwm > 1700) {  // 高位阈值（PWM > 1700）
    if (transition_state < TRANSITION_DONE) {
        gcs().send_text(MAV_SEVERITY_INFO, "Transition forced by CH12");
        transition_state = TRANSITION_DONE;
        in_forced_transition = false;
        transition_start_ms = 0;
        transition_low_airspeed_ms = 0;
    }
}
```

---

## 📊 工作原理

### **触发条件**
```
通道12 PWM > 1700 μs
```

### **执行动作**
```
1. 检查当前转换状态（transition_state < TRANSITION_DONE）
2. 如果正在转换中：
   - 发送GCS消息："Transition forced by CH12"
   - 设置 transition_state = TRANSITION_DONE
   - 清除强制转换标志
   - 重置转换计时器
3. 如果已完成转换：无操作
```

## ⚠️ 注意事项

### **1. 使用前提**
```
⚠️ 确保飞机状态适合固定翼飞行
⚠️ 检查空速是否足够
⚠️ 确认倾转电机位置正确

不满足条件时强制转换可能导致：
❌ 失速
❌ 控制失效
❌ 坠机
```

---

### **2. 高位阈值（1700 μs）**
```
为什么是1700？
- 避免误触发（中位1500 + 200余量）
- 确保是明确的高位信号
- 兼容大多数遥控器

可以修改阈值：
if (ch12_pwm > 1600) {  // 更敏感
if (ch12_pwm > 1800) {  // 更保守
```

---

### **3. 只能完成转换**
```
此功能只能：
✅ 强制完成转换（VTOL → 固定翼）

不能：
❌ 取消转换
❌ 反向转换（固定翼 → VTOL）
❌ 暂停转换

要取消转换需要切换飞行模式
```

## 📝 故障排除

### **问题1：通道12无效**
```
现象：打高位无反应
原因：
- 通道12未配置
- PWM值未达到1700
- 接收机问题

解决：
1. 检查遥控器通道12输出
2. 查看GCS中的RC12输入值
3. 确认PWM > 1700
```

---

### **问题2：误触发**
```
现象：转换意外完成
原因：
- 通道12信号干扰
- 开关位置错误

解决：
1. 检查通道12开关位置
2. 增加阈值（1700 → 1800）
3. 添加防抖动逻辑
```

---

### **问题3：强制转换后失速**
```
现象：强制完成后飞机失速
原因：
- 空速不足
- 倾转角度不对
- 过早强制转换

解决：
1. 确保空速足够（>15 m/s）
2. 检查倾转电机位置
3. 等待合适时机再强制
```
