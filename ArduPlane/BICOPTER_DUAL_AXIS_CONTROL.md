# 双旋翼双轴串级PID控制系统

## 概述

这是一个为双旋翼垂起飞行器设计的**双轴串级PID控制系统**，同时控制俯仰(Pitch)和偏航(Yaw)，采用经典的**角度环+角速度环**架构。

## 控制架构

```
┌─────────────────────────────────────────────────────────────┐
│                  双旋翼双轴串级PID控制                        │
└─────────────────────────────────────────────────────────────┘

俯仰通道（Pitch）：
  目标俯仰角 ──→ [外环PID] ──→ 期望俯仰角速度 ──→ [内环PID] ──→ 俯仰差分
                   ↑                              ↑
               当前俯仰角                      当前俯仰角速度

偏航通道（Yaw）：
  目标偏航角 ──→ [外环PID] ──→ 期望偏航角速度 ──→ [内环PID] ──→ 偏航差分
                   ↑                              ↑
               当前偏航角                      当前偏航角速度

组合输出：
  基础位置(0.5) + 俯仰差分 + 偏航差分 ──→ 左电机
  基础位置(0.5) - 俯仰差分 + 偏航差分 ──→ 右电机
```

## 控制原理

### 俯仰控制（Pitch）
- **左右电机反向**：实现俯仰力矩
- 抬头：左电机增加推力，右电机减少推力
- 低头：左电机减少推力，右电机增加推力

### 偏航控制（Yaw）
- **左右电机同向**：实现偏航力矩
- 左转：两个电机都增加推力（通过倾转角度差异产生偏航）
- 右转：两个电机都减少推力

### 组合输出公式

```cpp
left_motor  = 0.5 + pitch_diff + yaw_diff
right_motor = 0.5 - pitch_diff + yaw_diff
```

**示例**：
| 动作 | pitch_diff | yaw_diff | 左电机 | 右电机 | 效果 |
|------|-----------|----------|--------|--------|------|
| 悬停 | 0 | 0 | 0.5 | 0.5 | 平衡 |
| 抬头 | +0.3 | 0 | 0.8 | 0.2 | 抬头 |
| 低头 | -0.3 | 0 | 0.2 | 0.8 | 低头 |
| 左转 | 0 | +0.2 | 0.7 | 0.7 | 左转 |
| 右转 | 0 | -0.2 | 0.3 | 0.3 | 右转 |
| 抬头+左转 | +0.3 | +0.2 | 1.0 | 0.4 | 抬头左转 |

## 参数配置

### 基础参数
```
Q_TILT_ENABLE = 1        # 启用倾转功能
Q_TILT_TYPE = 3          # 设置为双旋翼模式
Q_FRAME_CLASS = 10       # 使用尾座式框架类
```

## 工作流程

### 1. 俯仰控制计算（50Hz）

**外环**：
```cpp
pitch_error = target_pitch - current_pitch
desired_pitch_rate = Kp*error + Ki*∫error + Kd*d(error)/dt
desired_pitch_rate = constrain(desired_pitch_rate, -MAX_RATE, +MAX_RATE)
```

**内环**：
```cpp
pitch_rate_error = desired_pitch_rate - current_pitch_rate
pitch_differential = Kp*error + Ki*∫error + Kd*d(error)/dt
pitch_differential = constrain(pitch_differential, -1.0, +1.0)
```

### 2. 偏航控制计算（50Hz）

**外环**：
```cpp
yaw_error = wrap_180(target_yaw - current_yaw)  // 处理360度环绕
desired_yaw_rate = Kp*error + Ki*∫error + Kd*d(error)/dt
desired_yaw_rate = constrain(desired_yaw_rate, -MAX_YAW_RATE, +MAX_YAW_RATE)
```

**内环**：
```cpp
yaw_rate_error = desired_yaw_rate - current_yaw_rate
yaw_differential = Kp*error + Ki*∫error + Kd*d(error)/dt
yaw_differential = constrain(yaw_differential, -1.0, +1.0)
```

### 3. 组合输出

```cpp
base_position = 0.5  // 中位

// 组合俯仰和偏航
left_motor  = base_position + pitch_differential + yaw_differential
right_motor = base_position - pitch_differential + yaw_differential

// 限制并输出
left_motor  = constrain(left_motor, 0.0, 1.0) * 1000
right_motor = constrain(right_motor, 0.0, 1.0) * 1000
```

## 调参流程

### 第一步：调整俯仰外环
1. 设置 `P_ANG_I = 0`, `P_ANG_D = 0`
2. 从 `P_ANG_P = 3.0` 开始逐步增大
3. 出现轻微振荡后减小20%

### 第二步：调整俯仰外环D
1. 从 `P_ANG_D = 0.05` 开始
2. 逐步增大观察振荡是否减小

### 第三步：调整俯仰外环I
1. 从 `P_ANG_I = 0.2` 开始
2. 观察稳态误差消除情况

### 第四步：调整俯仰内环
1. 按照相同方法调整 `P_RAT_P`, `P_RAT_I`, `P_RAT_D`
2. 内环响应应该比外环快

### 第五步：调整偏航控制
1. 重复步骤1-4，调整偏航参数
2. 偏航响应通常比俯仰慢，P增益可以稍小

### 第六步：组合测试
1. 测试俯仰+偏航组合动作
2. 观察是否有耦合振荡
3. 必要时微调参数

## 调试信息

系统每秒输出一次调试信息到GCS：
```
Bicopter P:2.3/45.2 Y:5.1/12.3 PD:0.25 YD:0.15
```

- **P**: 俯仰角度误差(度) / 期望俯仰角速度(度/秒)
- **Y**: 偏航角度误差(度) / 期望偏航角速度(度/秒)
- **PD**: 俯仰差分输出 (-1.0 到 1.0)
- **YD**: 偏航差分输出 (-1.0 到 1.0)

## 常见问题

### Q: 俯仰振荡
**A**: 
1. 减小 `P_ANG_P` 或 `P_RAT_P`
2. 增加 `P_ANG_D` 或 `P_RAT_D`
3. 检查机械结构是否松动

### Q: 偏航响应慢
**A**:
1. 增大 `Y_ANG_P`
2. 检查 `Y_MAX_R` 是否过小
3. 增加 `Y_RAT_P`

### Q: 俯仰和偏航耦合振荡
**A**:
1. 减小两个通道的P增益
2. 确保重心在两电机连线中点
3. 检查电机安装角度是否对称

### Q: 无法保持角度
**A**:
1. 增加外环I增益
2. 检查积分限幅是否过小
3. 确认电机推力足够

### Q: 偏航漂移
**A**:
1. 增加 `Y_ANG_I`
2. 检查陀螺仪校准
3. 确认磁罗盘工作正常

## 电机配置

双旋翼配置要求：
- **电机1（左）**：使用 `k_tiltMotorLeft` 通道
- **电机2（右）**：使用 `k_tiltMotorRight` 通道
- 两个电机应对称安装
- 重心必须在两电机连线中点
- 电机倾转轴应平行

## 控制逻辑说明

### 俯仰控制
```
抬头命令：
  左电机 = 0.5 + 0.3 = 0.8 (向前倾转，推力向下)
  右电机 = 0.5 - 0.3 = 0.2 (向后倾转，推力向上)
  结果：机头抬起
```

### 偏航控制
```
左转命令：
  左电机 = 0.5 + 0.2 = 0.7 (增加倾转角)
  右电机 = 0.5 + 0.2 = 0.7 (增加倾转角)
  结果：两侧推力方向变化产生偏航力矩
```

### 组合控制
```
抬头+左转：
  左电机 = 0.5 + 0.3(pitch) + 0.2(yaw) = 1.0
  右电机 = 0.5 - 0.3(pitch) + 0.2(yaw) = 0.4
  结果：机头抬起并左转
```

## 安全注意事项

1. **首次飞行前**：
   - 在地面测试所有参数
   - 确认电机转向和倾转方向正确
   - 检查俯仰和偏航控制方向
   - 测试组合动作

2. **飞行测试**：
   - 从悬停开始测试
   - 先测试单轴（俯仰或偏航）
   - 再测试组合动作
   - 准备好切换到手动模式

3. **参数调整**：
   - 每次只调整一个参数
   - 小幅度调整（10-20%）
   - 记录每次调整的效果
   - 先调俯仰，后调偏航

## 性能优化建议

1. **俯仰响应优先**：
   - 俯仰控制对稳定性最重要
   - 先调好俯仰再调偏航

2. **内环快于外环**：
   - 内环带宽应该是外环的3-5倍
   - 内环P增益通常较小

3. **积分项谨慎使用**：
   - I增益过大会导致超调
   - 积分限幅要合理设置

4. **微分项抑制振荡**：
   - D增益可以提高阻尼
   - 但过大会放大噪声
