# 双旋翼串级PID控制系统

## 概述

这是一个为双旋翼垂起飞行器设计的串级PID控制系统，采用经典的**角度环+角速度环**架构。

## 控制架构

```
目标俯仰角 ──→ [外环PID] ──→ 期望角速度 ──→ [内环PID] ──→ 电机差分输出
                 ↑                           ↑
              当前俯仰角                  当前角速度
```

### 外环：角度控制
- **输入**：俯仰角度误差 (目标角度 - 当前角度)
- **输出**：期望俯仰角速度
- **作用**：将角度误差转换为期望的旋转速度

### 内环：角速度控制
- **输入**：角速度误差 (期望角速度 - 当前角速度)
- **输出**：电机差分输出 (左右电机的差值)
- **作用**：通过调整左右电机推力差实现俯仰控制

## 参数配置

### 基础参数
```
Q_TILT_ENABLE = 1        # 启用倾转功能
Q_TILT_TYPE = 3          # 设置为双旋翼模式
Q_FRAME_CLASS = 10       # 使用尾座式框架类
```

### 外环参数（角度控制）

| 参数 | 说明 | 默认值 | 推荐范围 |
|------|------|--------|----------|
| `Q_TILT_BCP_ANG_P` | 角度P增益 | 4.5 | 3.0 - 8.0 |
| `Q_TILT_BCP_ANG_I` | 角度I增益 | 0.5 | 0.1 - 2.0 |
| `Q_TILT_BCP_ANG_D` | 角度D增益 | 0.1 | 0.0 - 0.5 |
| `Q_TILT_BCP_ANG_IMAX` | 角度积分限幅 | 30 deg/s | 20 - 50 |

**调参建议**：
- **P增益**：主要响应参数，增大会提高响应速度但可能引起振荡
- **I增益**：消除稳态误差，过大会导致超调
- **D增益**：抑制振荡，增强稳定性
- **IMAX**：限制积分项输出，防止积分饱和

### 内环参数（角速度控制）

| 参数 | 说明 | 默认值 | 推荐范围 |
|------|------|--------|----------|
| `Q_TILT_BCP_RAT_P` | 角速度P增益 | 0.15 | 0.08 - 0.3 |
| `Q_TILT_BCP_RAT_I` | 角速度I增益 | 0.1 | 0.05 - 0.2 |
| `Q_TILT_BCP_RAT_D` | 角速度D增益 | 0.003 | 0.001 - 0.01 |
| `Q_TILT_BCP_RAT_IMAX` | 角速度积分限幅 | 0.3 | 0.2 - 0.5 |

**调参建议**：
- **P增益**：控制角速度跟踪精度
- **I增益**：补偿系统延迟和干扰
- **D增益**：提供阻尼，减少振荡
- **IMAX**：限制电机差分输出的积分部分

### 限制参数

| 参数 | 说明 | 默认值 | 推荐范围 |
|------|------|--------|----------|
| `Q_TILT_BCP_MAX_RATE` | 最大期望角速度 | 200 deg/s | 100 - 400 |
| `Q_TILT_BCP_MAX_DIFF` | 最大电机差分 | 0.5 | 0.3 - 0.8 |

**说明**：
- **MAX_RATE**：限制外环输出，防止要求过高的角速度
- **MAX_DIFF**：限制左右电机的最大推力差，范围0-1

## 工作原理

### 1. 外环计算（50Hz）
```cpp
// 角度误差
pitch_error = target_pitch - current_pitch

// PID计算
desired_rate = Kp * pitch_error 
             + Ki * ∫(pitch_error * dt)
             + Kd * d(pitch_error)/dt

// 限制输出
desired_rate = constrain(desired_rate, -MAX_RATE, +MAX_RATE)
```

### 2. 内环计算（50Hz）
```cpp
// 角速度误差
rate_error = desired_rate - current_rate

// PID计算
motor_diff = Kp * rate_error
           + Ki * ∫(rate_error * dt)
           + Kd * d(rate_error)/dt

// 限制输出
motor_diff = constrain(motor_diff, -MAX_DIFF, +MAX_DIFF)
```

### 3. 电机输出
```cpp
// 获取基础油门
base_throttle = motors->get_throttle()

// 应用差分
left_motor = base_throttle + motor_diff   // 抬头时增加
right_motor = base_throttle - motor_diff  // 抬头时减少

// 输出到电机
output(left_motor, right_motor)
```

## 调参流程

### 第一步：调整外环P增益
1. 设置 `BCP_ANG_I = 0`, `BCP_ANG_D = 0`
2. 从 `BCP_ANG_P = 3.0` 开始
3. 逐步增大P，直到出现轻微振荡
4. 减小20%作为最终值

### 第二步：调整外环D增益
1. 从 `BCP_ANG_D = 0.05` 开始
2. 逐步增大D，观察振荡是否减小
3. 过大会导致高频噪声

### 第三步：调整外环I增益
1. 从 `BCP_ANG_I = 0.2` 开始
2. 观察是否能消除稳态误差
3. 过大会导致超调和振荡

### 第四步：调整内环参数
1. 按照相同方法调整内环P、I、D
2. 内环响应应该比外环快
3. 内环P增益通常较小（0.1-0.2）

### 第五步：调整限制参数
1. `MAX_RATE`：根据飞行器机动性能设置
2. `MAX_DIFF`：根据电机功率和重心位置设置

## 调试信息

系统每秒输出一次调试信息到GCS：
```
Bicopter: PE=2.3 DR=45.2 CR=42.1 MD=0.125
```

- **PE** (Pitch Error): 俯仰角度误差 (度)
- **DR** (Desired Rate): 期望角速度 (度/秒)
- **CR** (Current Rate): 当前角速度 (度/秒)
- **MD** (Motor Differential): 电机差分输出 (0-1)

## 常见问题

### Q: 飞行器振荡
**A**: 
1. 减小外环P增益
2. 增加外环D增益
3. 检查内环参数是否过大

### Q: 响应迟钝
**A**:
1. 增大外环P增益
2. 检查MAX_RATE是否过小
3. 增加内环P增益

### Q: 无法保持角度
**A**:
1. 增加外环I增益
2. 检查IMAX是否过小
3. 检查电机推力是否足够

### Q: 超调严重
**A**:
1. 减小外环I增益
2. 增加外环D增益
3. 减小外环P增益

## 电机配置

双旋翼配置要求：
- 电机1：左侧电机
- 电机2：右侧电机
- 两个电机应对称安装
- 重心应在两电机连线中点

## 安全注意事项

1. **首次飞行前**：
   - 在地面测试所有参数
   - 确认电机转向正确
   - 检查控制方向（抬头/低头）

2. **飞行测试**：
   - 从悬停开始测试
   - 逐步增加机动幅度
   - 准备好切换到手动模式

3. **参数调整**：
   - 每次只调整一个参数
   - 小幅度调整（10-20%）
   - 记录每次调整的效果
